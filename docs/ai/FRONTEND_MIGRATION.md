# Frontend Migration: Game Catalog Contract

> The frontend repository is not present in this workspace. This document records the active backend contract that frontend work must adopt.

## Breaking Changes

- Property GraphQL operations and types were removed without aliases.
- The primary types are now `Game`, `Games`, `GameInput`, `GameUpdate`, `AdminGameUpdate`, `GamesInquiry`, `AgentGamesInquiry`, and `AllGamesInquiry`.
- Replace Property operations with `createGame`, `getGame`, `updateGame`, `getGames`, `getAgentGames`, `likeTargetGame`, and the corresponding admin operations.
- Keep calling `getFavorites` and `getVisited`; both now return `Games`.
- `MemberType.AGENT`, `getAgents`, and Agent authorization remain unchanged.
- Generic Game comments use `CommentGroup.GAME`. Likes and views use `LikeGroup.GAME` and `ViewGroup.GAME`.

## Suggested UI Mapping

| Existing experience | Gameverse target |
| --- | --- |
| Property catalog/detail | Game catalog/detail |
| Agent properties | Agent-owned Games |
| Favorite properties | Favorite Games; wishlist remains a future feature |
| Visited properties | Recently viewed Games |
| Property moderation | Game catalog administration |
| Property upload target | `game` upload target |

## Catalog Behavior

- Public catalog and detail requests expose `ACTIVE` and `UPCOMING`, never `DELETE`.
- `isUpcoming` is a computed output; clients send `gameStatus` when authorized.
- Slugs are generated by the backend and do not change when titles change.
- FREE Games require zero pricing. PAID and PREMIUM Games require a positive base price; a nonzero discount must be lower than the base price.
- Ratings/reviews are output-only reserved counters. Continue using generic comments until the structured-review contract is introduced.

## Frontend Acceptance

- Regenerate GraphQL types from the new schema before changing pages.
- Remove all Property documents/fragments/cache assumptions.
- Cover anonymous, authenticated USER, AGENT owner, and ADMIN flows.
- Verify Game filters, pagination, media upload target, favorites, visited Games, comments, lifecycle states, and immutable slug links.
